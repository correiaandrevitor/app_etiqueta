📱 Etiquetas Pro - App de Orçamentos de Etiquetas
React Native
License: MIT

Etiquetas Pro é um aplicativo mobile completo para gerenciamento de orçamentos de etiquetas com sistema de autenticação de usuários. Desenvolvido com React Native, oferece uma interface moderna e intuitiva para calcular e salvar orçamentos de impressão de etiquetas.

✨ Funcionalidades
✅ Autenticação Completa
🆕 Registro de usuários com validação dupla (email + senha)
🔐 Login seguro com AsyncStorage
🚪 Logout automático
🔒 Validações: Senha mínima 6 caracteres, confirmação de email/senha
✅ Gerenciamento de Orçamentos
📊 Cálculo automático de total (quantidade × preço unitário)
📝 Campos obrigatórios: Quantidade, Tamanho, Material
💰 Preço com formatação brasileira (R$ 0,00)
💾 Salvar orçamentos localmente
🗑️ Excluir orçamentos com confirmação
✅ Interface Moderna
🎨 Design centralizado e responsivo
📱 Adaptável a todos tamanhos de tela
✨ Animações suaves e sombras
🎯 Navegação Stack fluida
